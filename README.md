# FutbolHub (uvlhub.io)

Repositorio de datasets de resultados de partidos de fútbol en formato CSV integrado con Zenodo/fakenodo siguiendo principios de Ciencia Abierta — Evolución y Gestión de la Configuración (EGC 2026-2027).
